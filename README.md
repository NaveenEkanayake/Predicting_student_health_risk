# HealthPredict — Student Wellness & Health Intelligence System

[![Next.js 14](https://img.shields.io/badge/Frontend-Next.js%2014-indigo)](https://nextjs.org/)
[![Express.js](https://img.shields.io/badge/Backend-Express.js-green)](https://expressjs.com/)

[![XGBoost](https://img.shields.io/badge/ML-XGBoost-orange)](https://xgboost.readthedocs.io/)
[![Gemini AI](https://img.shields.io/badge/AI-Google%20Gemini-purple)](https://ai.google.dev/)

A full-stack intelligence system for **Medical Personnel, School Nurses, and Health Officers** to monitor, analyze, and predict student health conditions using Machine Learning and Artificial Intelligence. Built with **Next.js 14 (App Router)** + **Express.js** + **MongoDB Atlas** + **XGBoost Classifier** + **Google Gemini AI**.

---

## Key Features

- **Medical Officer Portal**: Secure registration and login for healthcare staff and school health officers using JWT authentication and bcrypt password hashing.
- **Brand Splash Screen & Favicon**: Custom ECG waveform pulse brand logo and animated splash loader (`BrandLoader`) with smooth transitions during browser loads, login, and logout.
- **ML Health Condition Prediction**: XGBoost machine learning classifier predicts student health status (`Fit`, `Unhealthy`, `At-Risk`) with confidence scores and probability distributions.
- **Resilient AI Recommendations (Gemini AI)**: Personalized clinical recommendations generated by Gemini AI with multi-model fallback (`gemini-1.5-flash` / `gemini-1.5-pro`) and a smart local rule-based advisor fallback.
- **Export PDF Health Reports**: Generate and download professional A4 PDF health reports containing student demographic profiles, habit metrics, ML prediction outcomes, and full Gemini AI clinical advice.
- **Smooth Delete Confirmation Modal**: Custom glassmorphism modal with instant toast notifications for safe student record deletion.
- **Analytics & Dashboard Overview**: Interactive Recharts donut chart, prediction rate metrics, and real-time student health distribution.
- **Backend Fault Tolerance**: Asynchronous Python ML runner with a 5-second execution timeout and built-in JavaScript ML predictor fallback to eliminate socket hangup (`ECONNRESET`) errors.
- **Clean Icon Design**: Modern Lucide vector icons across all pages, forms, and backend logs (0 emojis).

## Setup & Installation

### Prerequisites

- **Node.js**: v18+ (LTS recommended)
- **Python**: 3.9+ with `pandas`, `scikit-learn`, `xgboost`, `joblib`
- **MongoDB Atlas Account**: Database instance (`student_health`)
- **Google Gemini API Key** *(Optional — system includes local clinical advice fallback)*

---

### 1. Clone & Install Dependencies

```bash
# Install Backend Dependencies
cd backend
npm install

# Install Frontend Dependencies
cd ../frontend
npm install

# Install Python ML Packages
pip install pandas scikit-learn xgboost joblib
```

---

### 2. Environment Configuration

Ensure `backend/.env` contains your connection credentials:

```env
PORT=5000
MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.vbqzgby.mongodb.net/student_health?retryWrites=true&w=majority
JWT_SECRET=student_health_jwt_secret_2026_key
GEMINI_API_KEY=your_gemini_api_key_here
```

---

### 3. Verify ML Model

Test the Python ML prediction script directly via CLI:

```bash
echo '{"sleep_duration":8,"daily_steps":10000,"diet_quality":"Good"}' | python backend/ml/predict.py
```

**Expected Output:**
```json
{
  "predicted_class": "Fit",
  "confidence": 98.5,
  "probabilities": { "At-Risk": 0.0, "Unhealthy": 1.5, "Fit": 98.5 }
}
```

---

### 4. Start Development Servers

**Terminal 1 — Express Backend API (Port 5000):**
```bash
cd backend
npm start
```

**Terminal 2 — Next.js Frontend (Port 3000):**
```bash
cd frontend
npm run dev
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser.

## API Documentation

### Authentication (`/api/auth`)

| Method | Endpoint | Description | Auth Required |
|--------|----------|-------------|---------------|
| `POST` | `/api/auth/register` | Register new Medical Personnel account | No |
| `POST` | `/api/auth/login` | Authenticate and obtain JWT token | No |
| `GET` | `/api/auth/me` | Fetch authenticated officer profile | Yes (`Bearer <token>`) |

---

### Student Management (`/api/children`)

| Method | Endpoint | Description | Auth Required |
|--------|----------|-------------|---------------|
| `GET` | `/api/children` | List all assigned student records | Yes |
| `POST` | `/api/children` | Create a new student record | Yes |
| `GET` | `/api/children/stats/overview` | Fetch dashboard analytics & distribution | Yes |
| `GET` | `/api/children/:id` | Fetch specific student details & history | Yes |
| `DELETE` | `/api/children/:id` | Remove a student record | Yes |

---

### Prediction & AI Advice (`/api/predict`)

#### `POST /api/predict`
Calculates student health prediction using the Python XGBoost engine and generates Gemini AI clinical suggestions.

**Request Body:**
```json
{
  "childId": "60d5f484f1a2c8b1f8e4e1a1",
  "sleepDuration": 8,
  "dailySteps": 9500,
  "dietQuality": "Good"
}
```

**Response (200 OK):**
```json
{
  "success": true,
  "prediction": {
    "result": "Fit",
    "confidence": 98.5,
    "probabilities": {
      "At-Risk": 0.5,
      "Unhealthy": 1.0,
      "Fit": 98.5
    }
  },
  "aiSuggestion": "is showing strong health indicators. Maintaining 8 hours of sleep and regular exercise will preserve optimal wellness."
}
```

## PDF Export Functionality

Medical personnel can click **"Download PDF Report"** on any completed student health prediction to instantly generate a printable A4 PDF:

- **Header**: Official `HealthPredict` title, date/time stamp, and confidentiality label.
- **Student Profile**: Full Name, Age, and Gender.
- **Health Habits**: Assessed Sleep Duration, Daily Steps, and Diet Quality rating.
- **Prediction Outcome**: Health status badge (`Fit`, `Unhealthy`, `At-Risk`), confidence percentage, and full probability breakdown.
- **AI Clinical Advice**: Complete AI health recommendations generated by Gemini.
- **Verification Footer**: Authorized Medical Officer signature block.
